# pixel-legal

The legal pages of the Android game Pixel Picasso, served by GitHub Pages at
<https://fancyfelicious.github.io/pixel-legal/>.

- `privacy.html` — the privacy policy. The game's settings and its store listing link to it.
- `impressum.html` — the legal notice (Impressum) under Austrian law, linked the same way.
- `index.html` — the start page that lists the documents.
- `style.css`, `icon.svg` — the look. No scripts, and nothing is loaded from another host.

A push to `main` publishes the pages. The addresses are linked from the app and the store listing, so
the repository and the files keep their names.
